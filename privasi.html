Kebijakan Privasi

Terakhir diperbarui: 1 November 2026

Kebijakan ini menjelaskan bagaimana Lumora mengumpulkan, menggunakan, menyimpan, dan melindungi data Anda saat menggunakan website dan layanan kami.

1. Data yang Kami Kumpulkan

  • Identitas: nama, email, nomor WhatsApp (via form konsultasi).
  • Detail kebutuhan: deskripsi proyek, file lampiran, catatan konsultasi.
  • Data transaksi: riwayat order, invoice, metode pembayaran.
  • Unggahan data: file data penelitian / bisnis yang Anda kirim untuk diolah.
  • Analitik: data agregat penggunaan website (pageview, device, browser) via Google Analytics 4.

2. Cara Kami Menggunakan Data

  • Menanggapi permintaan konsultasi dan menyediakan layanan yang Anda pesan.
  • Mengirim notifikasi order: status, invoice, dan hasil.
  • Memenuhi kewajiban kontraktual dan hukum.
  • Mengembangkan layanan berdasarkan tren permintaan (data agregat, tidak teridentifikasi).

3. Dasar Pemrosesan

Sesuai UU Pelindungan Data Pribadi (UU PDP), kami memproses data berdasarkan: persetujuan Anda saat mengisi form, pelaksanaan kontrak layanan, dan kewajiban hukum.

4. Penyimpanan & Keamanan

  • Seluruh trafik dienkripsi via HTTPS; data at rest dienkripsi di server.
  • Akses file berbasis peran; tautan unduhan bertanda waktu dan kedaluwarsa.
  • Backup harian dengan rencana pemulihan.
  • Audit trail untuk akses file sensitif.
  • Kebijakan retensi: file dihapus otomatis sesuai masa retensi yang Anda pilih atau berdasarkan UU.

6. Hak Anda

  • Akses: meminta salinan data yang kami simpan tentang Anda.
  • Perbaikan: meminta data yang salah diperbaiki.
  • Penghapusan: meminta penghapusan data Anda (subyek PDP) sesuai prosedur.
  • Portabilitas: menerima data Anda dalam format terstruktur.
  • Menarik persetujuan: berhenti menerima komunikasi pemasaran kapan saja.

7. Cookie & Analitik

Kami menggunakan cookie esensial untuk fungsi website, dan Google Analytics 4 untuk memahami bagaimana halaman digunakan. Tidak kami gunakan cookie iklan pihak ketiga.
