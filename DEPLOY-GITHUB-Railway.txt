============================================================
  DEPLOY LUMORA: GitHub + Railway + Neon (Panduan Lengkap)
============================================================

Kamu udah punya: akun GitHub + akun Railway + paket Hobby ($5).
Yang mau: deploy full (website + portal + admin + database).

ALUR:
  [GitHub repo] --> [Railway]  ==> service backend + frontend
                  [Neon DB]    ==> data (persist)

Railway jalanin backend Node yang juga serve file statis,
jadi 1 service udah ngambilin semua (HTML + API + DB).


------------------------------------------------------------
BAGIAN 1 - SIAPKAN GITHUB REPO (sekali aja)
------------------------------------------------------------
1. Buka https://github.com, bikin repo baru:
   - Nama: lumora (atau sesukamu)
   - Pilih "Public" (atau Private, sama)
   - JANGAN ceklis "Add a README" / .gitignore (ada yang udah
     di-pakai). Biarin kosong, kita isihin dari komputer.

2. Di komputer, di folder lumora, buka terminal (cmd/PowerShell):

   cd C:\Users\emirz\Downloads\lumora

3. Git init + commit:

   git init
   git add .
   git commit -m "deploy lumora"

   (Kalau tanya "Enter your email" saat commit pertama kali:
    git config --global user.email "emailmu@gmail.com"
    git config --global user.name  "namamu"
    terus ulangi  git add . lalu git commit )

4. Push ke GitHub:

   git branch -M main
   git remote add origin https://github.com/USERNAME/lumora.git
   git push -u origin main

   (Ganti USERNAME sama username GitHub kamu)

   Nanya login GitHub -> milih "login with browser" -> masuk
   ke github -> approve. Selesai, kode udah ada di GitHub.


------------------------------------------------------------
BAGIAN 2 - BUAT DATABASE NEON (Postgres)
------------------------------------------------------------
1. Buka https://neon.tech -> Sign in (pakai akun sama / Google).
2. Klik "New Project", kasih nama: lumora
   Region: pilih yang deket (mis. "Asia Pacific" / "EU").
3. Tunggu beberapa detik sampai DB jadi.
4. Klik menu "Connect" di kiri, bagian "NodeJS / psql
   Connection String".
5. GUNAKAN yang labeled "Pooled" (bukan direct) kalau ada.
   Stringnya bentuknya:
   postgres://USER:PASS@ep-host.region.pooler.n...?pgbouncer=true
   atau tanpa ?
   COPY string itu - ini DATABASE_URL kamu.
   (jangan di-share ke publik, di-simpan di Railway rahasia)

   Bonus: Neon punya button "Copy". Klik itu.


------------------------------------------------------------
BAGIAN 3 - HUBUNGAN RAILWAY & GITHUB
------------------------------------------------------------
1. Buka https://railway.app -> Sign in (pakai akun Railwaymu).
2. Klik "New Project" -> "Deploy from GitHub repo".
3. Autorize GitHub (Railway minta akses repo) -> pilih
   repo lumora kamu -> Next.
4. Nama service: lumora. Klik "Create".
5. Railway auto:
   - detect Node.js (karena server/package.json)
   - npm install
   - pake start_command dari railway.toml
   Semua udah kita set sebelumnya.


------------------------------------------------------------
BAGIAN 4 - SET ENVIRONMENT VARIABLES DI RAILWAY
------------------------------------------------------------
1. Di panel Railway, klik service "lumora" -> tab "Variables".
2. Tambah 2 variable:

   DATABASE_URL   = (paste connection string dari Neon)
   JWT_SECRET     = (string acak panjang, mis.
                    "lumora-r4h4si4-2026-ab12cd34")

   (Semua "Add" -> Save.)

   TIPS CEK: Railway baru bisa "Connect a Neon database"
   langsung dari panel (icon "Databases"). Kalau pakai
   fitur itu, Railway auto-bikin + isi DATABASE_URL,
   jadi skip bagian bikin Neon manual.


------------------------------------------------------------
BAGIAN 5 - JALANKAN + UJI
------------------------------------------------------------
1. Di Railway, klik "Redeploy" (icon refresh) biar deploy
   ulang pake env baru.
2. Tunggu sampai hijau (status "Ready").
3. Klik tab "Networking" -> "Generate Domain" atau buka
   "Public Networking" -> copy URL
   (bentuk: https://lumora-production.up.railway.app)
4. Buka URL itu di browser.
   Cek:
   - Situs beranda: https://URL          (index.html)
   - Portal : https://URL/portal.html  (login dewi@mail.com / dewi123)
   - Admin  : https://URL/admin.html   (login admin@lumora.id / admin123)
   - Form: isi -> cek leads di panel Neon:
       SELECT * FROM leads ORDER BY created_at DESC;

5. Kalau error:
   - "DATABASE_URL belum diset" -> cek tab Variables,
     apakah DATABASE_URL terisi.
   - "connect ETIMEOUT" / "getaddrinfo" -> cek region
     Neon vs Railway sama & string bener.
   - "role does not exist" -> pakai connection string
     "Primary/Read-write", bukan replica.

PERSOALAN UPLOAD FILE:
File upload klien (order data) disimpan di /uploads folder
server. Di Railway, filesystem TIDAK persist (hilang saat
redeploy). Solusi:
- (sekarang) pakai saja - data order + users tetap di Neon
  (persist), cuma file-nya hilang saat redeploy
- (nanti) ganti ke S3-compatible storage (Cloudflare R2 /
  AWS S3) untuk file-nya. Ini upgrade tahap berikutnya.
